# Kivi ♻️

> A modern take on Kiwi.

Kivi is a future terminal editor based on the ideas and editing model of [Kiwi](https://github.com/0x4D696E61/Kiwi).

It will keep Kiwi's WASD-first modal editing and keyboard-driven workflow while introducing a more modern interface inspired by today's terminal editors and IDEs.

## Planned

- Modern TUI
- File explorer
- Editor tabs
- Split views
- Integrated terminal
- Command palette
- LSP support
- Autocomplete and diagnostics
- Git integration
- Expanded theming
- Mouse support

## Kiwi and Kivi

Kivi is not replacing Kiwi.

**Kiwi** will continue as the lightweight, focused terminal editor.

**Kivi** will build on the same ideas with a larger, more modern interface and additional IDE-like features.

Both projects will continue to be maintained.

## Status

Kivi is currently in the planning stage.

Development will begin as Kiwi's core continues to mature.
